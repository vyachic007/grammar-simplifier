# Grammar Simplifier

Консольное Java-приложение для устранения **пустых (ε-)** и **цепных правил** контекстно-свободных грамматик. Разработано для практического занятия № 2 «Приведение грамматик. Устранение пустых и цепных правил».

## Возможности

- Ввод грамматики пользователем, без заранее заданных правил.
- Устранение пустых правил с выводом последовательности множеств укорачивающих нетерминалов `W0`, `W1`, …
- Устранение цепных правил с выводом цепных множеств `N(A)` для каждого нетерминала.
- Последовательное выполнение обоих преобразований.
- Сохранение пустой цепочки с помощью нового начального символа, если исходный начальный символ порождает `ε`.
- Вывод исходной и преобразованной грамматик, устранение повторяющихся альтернатив.
- Повторный запуск преобразований через главное меню без перезапуска приложения.

## Требования

- **Java 17** или новее.
- Сторонние библиотеки не требуются.

## Запуск

Откройте проект в **IntelliJ IDEA** и запустите метод `main()` класса `by.slava_borisov.grammarsimplifier.Main`.

Если исходный файл расположен по пути `src/by/slava_borisov/grammarsimplifier/Main.java`, можно запустить из терминала в корне проекта:

```bash
javac -encoding UTF-8 -d out src/by/slava_borisov/grammarsimplifier/Main.java
java -cp out by.slava_borisov.grammarsimplifier.Main
```

## Главное меню

```text
=== УПРОЩЕНИЕ ГРАММАТИК ===
1 — удалить пустые правила
2 — удалить цепные правила
3 — удалить пустые и цепные правила
0 — выход
Выбор:
```

После выбора режима программа запрашивает **количество строк с правилами**, затем сами правила. Первое правило задаёт начальный символ.

## Формат правил

```text
S -> AB | a | ε
A -> aA | b
B -> b | ε
```

- Левая часть: один нетерминал, например `S`, `A`, `B`, `S0`.
- Стрелка: `->` или `→`.
- Альтернативы разделяются символом `|`.
- Пустая цепочка обозначается `ε` и записывается отдельной альтернативой.
- Все используемые нетерминалы должны иметь определённые правила.
- Поддерживаются терминалы в виде строчных последовательностей (`a`, `b`, `and`, `not`), а также отдельные знаки (`(`, `)`, `:=` и др.).

## Пример: устранение пустых правил

**Ввод:**

```text
Выбор: 1
Количество строк с правилами: 3
S -> aAB | bA | ε
A -> aAB | ε
B -> bB | c
```

**Вывод:**

```text
Исходная грамматика:
Начальный символ: S
S → a A B | b A | ε
A → a A B | ε
B → b B | c

Этап 1. Устранение пустых правил:
W0 = [S, A]
W1 = [S, A]
Начальный символ порождает ε. Добавлен S0 → S | ε
Полученная грамматика:
Начальный символ: S0
S0 → S | ε
S → a A B | a B | b A | b
A → a A B | a B
B → b B | c
```

Новый начальный символ `S0` нужен для сохранения возможности вывода пустой цепочки. Если выбрать режим `3`, программа затем устранит и цепные правила.

## Как работают алгоритмы

### Пустые правила

1. Находится `W0` — множество нетерминалов, непосредственно выводящих `ε`.
2. Множество расширяется нетерминалами, правые части которых состоят только из уже найденных укорачивающих нетерминалов.
3. Для каждого правила строятся варианты с исключением укорачивающих символов.
4. Удаляются пустые альтернативы, кроме специально сохранённой `S0 → ε`, когда это необходимо.

### Цепные правила

1. Для каждого нетерминала находятся символы, достижимые по цепным переходам вида `A → B`.
2. Выводятся множества `N(A)`.
3. Нецепные правила достижимых символов переносятся к исходному нетерминалу.
4. Цепные правила исключаются.

## Особенности реализации

- `LinkedHashMap` хранит правила по нетерминалам с сохранением порядка ввода.
- `LinkedHashSet` исключает повторяющиеся альтернативы.
- Рекурсивное построение вариантов используется при устранении пустых правил.
- Очередь `Queue` применяется для обхода цепных переходов.
- Программа проверяет формат ввода и наличие правил для используемых нетерминалов.

## Ограничения

Приложение работает с грамматиками в описанном выше формате и **не выполняет** полное приведение к нормальной форме Хомского или Грейбах. Оно предназначено именно для двух преобразований: устранения пустых и цепных правил.
